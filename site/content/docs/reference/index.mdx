## Conventions

Reference material adheres to the following standards:

1. **Structured layouts**: Options, variables, and schema keys are presented in type tables.
2. **Exhaustive coverage**: Defaults, accepted types, constraints, and error values are documented completely.
3. **Factual tone**: Descriptions focus strictly on technical realities and syntax constraints.
4. **Minimal examples**: Code snippets provide copy-pasteable syntax rather than end-to-end tutorials.
