## Conventions

Every tutorial in DevTools adheres to strict authoring rules:

1. **Linear sequence**: Instructions follow a step-by-step path from a clean checkout to a working outcome.
2. **Immediate verification**: Each command includes the expected output so you can verify success before continuing.
3. **Focused scope**: Lessons avoid configuration diversions and focus strictly on the standard workflow.
